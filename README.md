# Sales Data Analysis Dashboard

Projeto de análise de dados utilizando PostgreSQL e Power BI.

## Tecnologias utilizadas

- PostgreSQL
- SQL
- Power BI

## Objetivo

Analisar dados de vendas para identificar padrões de faturamento, regiões com maior desempenho e categorias de produtos mais vendidas.

## Análises realizadas

- Total de vendas
- Total de lucro
- Total de produtos vendidos
- Vendas por região
- Vendas por categoria
- Vendas ao longo do tempo
- Top 10 produtos mais vendidos

## Dashboard

O dashboard foi desenvolvido no Power BI utilizando dados armazenados em PostgreSQL.

## Estrutura do projeto

dataset → arquivo CSV com os dados de vendas  
sql → consultas SQL utilizadas nas análises  
dashboard → arquivo do Power BI
